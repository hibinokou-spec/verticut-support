# verticut-support

Support site and privacy policy for **VertiCut**, published with GitHub Pages at
`https://hibinokou-spec.github.io/verticut-support/`.

| page | URL path |
|---|---|
| Support (ja / en) | `/` · `/index-en.html` |
| Privacy Policy (ja / en) | `/privacy.html` · `/privacy-en.html` |
| App Review demo clip | `/demo/verticut-demo.mp4` (added when the generated stills exist) |

There is no terms page: VertiCut uses Apple's standard EULA (Phase 7 D10).

The privacy policy states what the app's code does. If the app starts storing,
sending or reading anything new, this page and the App Store privacy answers
change with it.
